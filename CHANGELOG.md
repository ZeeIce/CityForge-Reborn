# Changelog

## 1.2.0

The Control update.

- New: hotkey to open and close the panel (Ctrl+Shift+C by default, rebind it in Options)
- New: a status strip next to the CityForge button lists the cheats that are on; click it to open the panel
- Changed: "Keep achievements enabled" can only be changed from the main menu, before a city is loaded
- Fixed: settings could fail to save. The game drops saves when its shared save queue is full, and found the file by a class name many mods share; CityForge now uses its own name, waits for slider changes to settle, checks the file was written and retries

## 1.1.0

- New: unlimited water
- New: unlimited electricity
- New: no pollution (air, ground, noise and groundwater)

## 1.0.0

First public release.

- Money, milestones and development points
- Instant construction and build speed
- Move-in and tourist boosts
- Happiness, education and rich citizen cheats
- Building level-up, efficiency and storage
- Demand control for every zone, with Force Build
- Panel colours and keep-achievements option
